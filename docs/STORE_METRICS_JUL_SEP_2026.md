# HAMODY metrics, July–September 2026

Prepared 26 October 2026. Months run on Asia/Dubai time. Money is AED. This is the public website. Orders typed in by staff are not included. Deleted orders are not included.

A sales order is a website order that was placed. Cancelled orders are left out. Failed card, Tabby, and Tamara attempts are left out. Checkouts still waiting for payment are left out. Cash on delivery is included when the customer places the order.

Visitors in this report are Google Analytics active users for each full month:

| Month | Active users |
| --- | ---: |
| July | 183,389 |
| August | 118,308 |
| September | 67,777 |
| **Sum of the three months** | **369,474** |

An active user is a person Analytics counted in that month. The three-month total adds the months together, so a person who visited in two months is counted twice. These are not the smaller session counts saved by the store.
